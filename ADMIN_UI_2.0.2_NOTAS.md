# Bilar DigitalTech Solutions — Admin UI 2.0.2

## Ajustes desta versão
- Removido o segundo logo da sidebar; o logo oficial fica apenas no cabeçalho.
- Cabeçalho administrativo redesenhado com hierarquia visual, função do utilizador e estado da página.
- Pesquisa do painel transformada numa pesquisa funcional com resultados de páginas, produtos, serviços, projectos, equipa e insights.
- Sidebar refinada com navegação mais limpa, estado activo e identificação do Centro de Gestão sem repetir a marca.
- Dashboard com espaçamento, cards e sombras mais consistentes.
- Mantida a identidade azul/navy + verde/turquesa da Bilar.
- Mantido o servidor local na porta 5530.

## Nota de validação
A pasta foi preparada sem `node_modules`. A instalação das dependências deve ser feita no computador de desenvolvimento com `npm install` antes de executar `npm run dev` ou `npm run build`.
